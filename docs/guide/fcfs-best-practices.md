# Tips & Best Practices

A few recommendations for getting the best results on FCFS sites.

---

## Have everything ready before the drop

The worst time to set up your proxies or fill your profiles is during the drop. Make sure all of this is done **in advance**:

- [ ] Accounts generated and profiles filled (delivery address)
- [ ] Payment cards configured
- [ ] SOCKS5 proxies imported
- [ ] CapSolver key configured and balance topped up
- [ ] Monitor configured and connected (Discord token, channels, filters)
- [ ] Buy task parameters memorized (ready to re-create quickly)

:::tip Know your task settings
Once you find buy task settings that work, note them down. The structure (account group, proxy group, quantity) stays the same across drops — only the URL or trigger changes.
:::

---

## Keep Discord notifications on

Turn on notifications for the Discord channels you're monitoring. Even with the Monitor running, it's good to know when a drop is happening so you can watch the task progress.

---

## Test before a real drop

Create one test buy task with a non-limited product to verify:
- Proxy connects correctly
- Account logs in
- Checkout flow completes

This catches configuration issues before they cost you a drop.

---

## Site-specific notes

**Fnac** — Relay point selection is supported. Pre-configure your preferred relay in Settings.

**Philibert** — Profile fill must include full delivery address. Tasks use HTTP direct checkout for speed.

**King Jouet** — Adyen card payment. CVV is auto-entered. Make sure your card is correctly configured.

**Shopify** — Works with any Shopify store. URL must be a direct product or variant URL.

---

## Need help?

The **Orbit Discord** is the best place to ask questions, share what's working, and get alerts on upcoming drops. Stay active there — community intelligence is a major edge on competitive drops.
