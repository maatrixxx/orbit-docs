# Step 2 — SMS API

Amazon requires a **phone number** to complete account registration. Orbit handles this 100% automatically — you just need to connect an SMS API and it does the rest.

---

## Recommended provider — Hero SMS

**[hero-sms.com](https://hero-sms.com/fr)**

Hero SMS is the service we recommend. It works directly with Orbit and offers great number availability for Amazon FR and UK at very competitive rates.

| Detail | Info |
|--------|------|
| Price per number | $0.05 – $0.30 depending on country |
| Supported by Orbit | Yes (native integration) |
| Minimum deposit | A few dollars is enough to get started |

---

## How to get your API key

1. **Create an account** at [hero-sms.com](https://hero-sms.com/fr)
2. **Top up your balance** — even $1–2 is enough to start testing
3. Go to your **dashboard** → look for the **"API"** or **"API Key"** section in the menu
4. Copy your API key (a long string of characters)
5. In Orbit → **Settings** → **SMS** → paste your key and click **Save**

:::tip Orbit does everything automatically
Once your API key is saved, you never touch it again. When a task reaches the phone verification step, Orbit rents a number, receives the SMS, enters the code, and releases the number — all without any action from you.
:::
